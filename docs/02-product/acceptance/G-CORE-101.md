# G-CORE-101 Acceptance Contract

- **Goal:** Verify deployment rollback and recovery
- **Capability class:** release.
- **Authority:** Core BFF runtime and deployment SOTs.
- **Acceptance:** the declared continuation capability is executable, observable, secure, reproducible, and verified against the exact revision.
- **Out of scope:** unrelated product behavior, unapproved production mutation, and unsupported external platform claims.
