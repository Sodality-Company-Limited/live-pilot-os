## 🏛️ Executive Summary

This acceptance contract defines the formal verification and empirical assurance criteria for Goal G-ML-005: Autoregressive Language-Preservation Objective Specification. Soda OS establishes a PyTorch loss module (`LanguagePreservationLoss`) that combines masked negative log-likelihood (NLL) token cross-entropy loss on completion spans with a reference model Kullback-Leibler (KL) divergence penalty. This composite loss objective guarantees that training auxiliary confidence heads or fine-tuning parameter-efficient adapters does not induce catastrophic forgetting or degrade base causal language fluency and reasoning capabilities.

## 🧪 BDD Given-When-Then Acceptance Scenarios

### Scenario 1: AC-ML-005-01: Prompt-Masked Negative Log-Likelihood Token Loss
```gherkin
Feature: Prompt-Masked Negative Log-Likelihood Loss
  Scenario: Loss module penalizes only completion tokens and ignores prompt tokens
    Given student language model logits of shape [batch, seq_len, vocab_size]
    And target token IDs of shape [batch, seq_len] with prompt tokens masked (via prompt_mask or ignore_index)
    When passed through LanguagePreservationLoss forward computation
    Then causal shift alignment is performed (logits[:-1] predicting labels[1:])
    And the resulting NLL loss is non-negative and finite
    And prompt tokens have zero gradient contribution and zero impact on the loss value
    And computation executes with real PyTorch autograd graph with zero mocks and zero stubs.
```

### Scenario 2: AC-ML-005-02: Reference Model KL Divergence Regularization
```gherkin
Feature: Reference Model KL Divergence Regularization
  Scenario: KL penalty penalizes distributional drift from frozen base reference model
    Given student model logits of shape [batch, seq_len, vocab_size]
    And reference model logits of shape [batch, seq_len, vocab_size]
    When compute_kl_divergence is invoked with regularization coefficient beta > 0.0
    Then KL divergence equals 0.0 when student logits equal reference logits identically
    And KL divergence is strictly non-negative for differing distributions
    And the total loss equals NLL_loss + beta * KL_loss.
```

### Scenario 3: AC-ML-005-03: Numerical Stability and Gradient Backpropagation
```gherkin
Feature: Numerical Stability and Gradient Invariants
  Scenario: Gradient backpropagation executes cleanly without NaN or Inf under extreme values
    Given student logits with extreme values (e.g. logits exceeding +/- 1000.0)
    And valid target labels and reference logits
    When loss.backward() is executed on trainable parameters
    Then all trainable parameters receive non-null, finite gradients (no NaN or Inf)
    And invalid non-finite tensor inputs (NaN or Inf in inputs) trigger fail-closed ValueError
    And empty batch inputs trigger fail-closed ValueError.
```
