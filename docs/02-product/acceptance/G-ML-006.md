## 🏛️ Executive Summary

This acceptance contract defines the formal verification and empirical assurance criteria for Goal G-ML-006: Calibrated RLCD Reward and Asymmetric Loss Function. Soda OS establishes a PyTorch loss module (`CalibratedRewardLoss`) that combines proper logarithmic scoring, Brier distance regularization, asymmetric quadratic overconfidence penalties for wrong decisions, and evidence scaling penalties. This objective guarantees that autonomous agents are severely penalized for confident hallucinations while being incentivized to output honest, calibrated uncertainty estimates.

## 🧪 BDD Given-When-Then Acceptance Scenarios

### Scenario 1: AC-ML-006-01: Asymmetric Overconfidence Penalty and Monotonicity
```gherkin
Feature: Asymmetric Overconfidence Penalty and Monotonicity
  Scenario: Incorrect decisions asserted with high confidence receive severely amplified loss
    Given predicted confidence values c in [0.0, 1.0] and incorrect target outcomes (y* = 0)
    When passed through CalibratedRewardLoss forward computation
    Then the computed loss monotonically increases as confidence c approaches 1.0
    And the loss for an incorrect prediction at c = 0.95 is at least 5x higher than at c = 0.20
    And computation executes with real PyTorch autograd graph with zero mocks and zero stubs.
```

### Scenario 2: AC-ML-006-02: Boundary Numerical Stability and Epsilon Clamping
```gherkin
Feature: Boundary Numerical Stability and Epsilon Clamping
  Scenario: Loss computation remains finite with zero NaN or Infinity at extreme confidence bounds
    Given predicted confidence values at exact boundary limits c in {0.0, 1.0}
    And target labels y* in {0, 1}
    When passed through CalibratedRewardLoss forward computation
    Then all loss components (proper_loss, overconfidence_penalty, brier_loss, evidence_penalty, total_loss) are finite non-negative numbers
    And zero NaN or Infinity values are emitted
    And non-finite tensor inputs trigger fail-closed ValueError.
```

### Scenario 3: AC-ML-006-03: Evidence-Penalty Scaling and Monotonic Downward Reward
```gherkin
Feature: Evidence-Penalty Scaling
  Scenario: Absence of verified evidence scales the reward downwards monotonically
    Given candidate decisions with confidence c > 0.0
    When evaluated with verified evidence (evidence_verified = 1.0) versus unverified evidence (evidence_verified = 0.0)
    Then unverified evidence induces an explicit evidence penalty proportional to confidence
    And the corresponding scalar reward (reward = -loss) decreases monotonically as evidence verification decreases.
```

### Scenario 4: AC-ML-006-04: Autograd Backpropagation and Gradient Precision
```gherkin
Feature: Autograd Backpropagation and Gradient Stability
  Scenario: Analytical gradients match numerical gradients within tight precision bounds
    Given double precision (float64) confidence tensors with requires_grad=True
    And valid ground truth target tensors
    When torch.autograd.gradcheck is executed on CalibratedRewardLoss
    Then gradcheck returns True with analytical gradient precision <= 10^-5
    And backpropagation yields non-zero finite parameter gradients.
```
