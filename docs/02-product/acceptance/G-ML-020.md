# Acceptance Contract: G-ML-020

**Goal:** G-ML-020: CI Calibration Gate and Quality Policy Enforcement  
**Epic:** ML  
**Version:** 1.0.0  
**Status:** active  

---

## 1. Feature Definition

```gherkin
Feature: CI Calibration Gate and Quality Policy Enforcement
  As a CI/CD Pipeline and Soda OS Quality Gatekeeper
  I want an automated CI verification gate evaluating calibration metrics, Brier scores, and autonomous routing safety
  So that model miscalibration, degraded routing logic, and high-risk safety violations are programmatically blocked from merging into the codebase.
```

---

## 2. BDD Given-When-Then Scenarios

### Scenario 1: Successful Gate Execution on Fully Compliant Metrics
```gherkin
Scenario: Exit Code 0 on Compliant Calibration Suite
  Given a calibration evaluation report or dataset satisfying all SLA thresholds:
    | metric                      | threshold | value   |
    | expected_calibration_error  | <= 0.0400 | 0.0210  |
    | brier_score                 | <= 0.0800 | 0.0350  |
    | high_confidence_error_rate  | <= 0.0100 | 0.0050  |
  And zero unverified high-risk decisions routing to proceed
  When `node scripts/ci/ci-calibration-gate.mjs --artifact <report>` is executed
  Then the process MUST exit with code 0
  And the console output MUST report all checks passed.
```

### Scenario 2: Blocking Gate Failure on ECE Breach
```gherkin
Scenario: Exit Code 1 on Expected Calibration Error Breach (> 0.0400)
  Given a calibration report where ECE is 0.0520 (exceeding ceiling 0.0400)
  When `node scripts/ci/ci-calibration-gate.mjs --artifact <report>` is executed
  Then the process MUST exit with code 1
  And the output MUST report an ECE SLA violation with measured value and ceiling.
```

### Scenario 3: Blocking Gate Failure on Brier Score Breach
```gherkin
Scenario: Exit Code 1 on Brier Score Breach (> 0.0800)
  Given a calibration report where Brier score is 0.0950 (exceeding ceiling 0.0800)
  When `node scripts/ci/ci-calibration-gate.mjs --artifact <report>` is executed
  Then the process MUST exit with code 1
  And the output MUST report a Brier score SLA violation.
```

### Scenario 4: Blocking Gate Failure on High-Confidence Error Rate Breach
```gherkin
Scenario: Exit Code 1 on High-Confidence Error Rate Breach (> 1.0%)
  Given a calibration report where high_confidence_error_rate is 0.0250 (2.5% > 1.0%)
  When `node scripts/ci/ci-calibration-gate.mjs --artifact <report>` is executed
  Then the process MUST exit with code 1
  And the output MUST report a high-confidence error rate violation.
```

### Scenario 5: Blocking Gate Failure on Unverified High-Risk Routing to Proceed
```gherkin
Scenario: Exit Code 1 on Unverified High-Risk Decision Routing to Proceed
  Given a routing decision dataset containing a high-risk decision with unverified evidence
  When the routing state machine or decision log assigns action `proceed`
  Then the calibration gate MUST immediately fail with exit code 1
  And log a critical security routing invariant violation.
```

### Scenario 6: CLI Help Flag Contract
```gherkin
Scenario: Display CLI Options on --help
  When `node scripts/ci/ci-calibration-gate.mjs --help` is invoked
  Then the output MUST display available flags (`--artifact`, `--strict`, `--report`, `--help`)
  And the process MUST exit cleanly with exit code 0.
```

### Scenario 7: Fail-Closed Behavior on Missing or Corrupt Artifact
```gherkin
Scenario: Fail Closed on Missing Artifact
  Given a path to a non-existent artifact file
  When `node scripts/ci/ci-calibration-gate.mjs --artifact /non/existent/file.json` is invoked
  Then the process MUST exit with code 1
  And log a file not found error without throwing an unhandled exception.
```
