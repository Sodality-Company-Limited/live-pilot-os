## 2. BDD Given-When-Then Scenarios

### Scenario 1: Architecture Specification and Mathematical Formulations
```gherkin
Scenario: Architecture document defines complete mathematical calibration formulas
  Given the architecture document at `docs/03-architecture/confidence-aware-execution.md`
  When an engineer or automated validator inspects the contents
  Then it MUST contain explicit mathematical formulas for RLCD loss, Expected Calibration Error (ECE), Brier Score, and High-Confidence Error Rate (HCER)
  And it MUST document the complete 8-case routing truth table
  And all referenced source files MUST exist on disk.
```

### Scenario 2: Architectural Decision Record ADR-004
```gherkin
Scenario: ADR-004 establishes formal decision records for calibrated confidence routing
  Given the architectural decision record at `docs/05-decisions/ADR-004-calibrated-confidence-routing.md`
  When inspected by technical reviewers
  Then it MUST contain standard sections: Status, Deciders, Context, Decision, Consequences, and Alternatives Considered
  And the status MUST be marked as "accepted"
  And it MUST reference the concrete implementation in `scripts/lib/confidence-calibration.mjs`.
```

### Scenario 3: Incident Response and Operator Runbooks
```gherkin
Scenario: Operator runbook provides step-by-step troubleshooting playbooks
  Given the workflow guide at `docs/06-workflows/confidence-aware-execution.md`
  When an operator encounters a CI calibration gate breach, distribution drift alert, or circuit breaker trip
  Then the runbook MUST provide step-by-step diagnostic CLI commands
  And it MUST provide remediation procedures for each incident category
  And the file MUST maintain 100% zero-drift parity with `template/docs/06-workflows/confidence-aware-execution.md`.
```

### Scenario 4: Automated Verification Pass
```gherkin
Scenario: Documentation suite passes automated unit test and link verification
  Given the unit test suite at `tests/unit/test-operational-runbook.mjs`
  When executed via `node tests/unit/test-operational-runbook.mjs`

  And zero dead markdown links or missing touch map files MUST be found.
```
