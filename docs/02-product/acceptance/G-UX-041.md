**Pain:** P-001 · **Evidence:** E-001

## Acceptance criteria

1. The UX flow documents distinct Host and Live Ops views connected to one shared simulated live session.
2. The demo scenario is traceable from chat to audience topic/product signal, Live Ops offer decision, and Host cue.
3. Both views specify empty, loading, error, partial, and success states, including data preservation/recovery behavior.
4. Responsive behavior is stated for sm, md, and lg; reading order, keyboard focus, screen-reader announcements, contrast, and reduced motion are specified.
5. Tokens define one dark theme with Shopee orange, spacing/type/radius/breakpoint/motion scales, and documented WCAG AA checks.
6. The global Soda OS design-token specification remains unchanged.
7. Product/Design explicitly approves all design artifacts before implementation begins.
