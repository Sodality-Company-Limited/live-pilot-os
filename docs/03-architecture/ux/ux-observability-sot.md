# LivePilot OS — UX Observability SOT

> **Status:** Production-readiness target for privacy-safe UX telemetry.

Track screen load, component state transitions, action latency, suggestion acceptance/
edit/rejection, approval completion, error-code exposure, realtime disconnect/replay,
locale fallback, accessibility failures, and Web Vitals. Every event carries tenant-
safe session context, correlation ID, component/screen version, and mode without PII,
tokens, prompts, or sensitive commerce values.

Telemetry is diagnostic, not business truth. Retention, consent, sampling, redaction,
and alert ownership must be explicit before production.
