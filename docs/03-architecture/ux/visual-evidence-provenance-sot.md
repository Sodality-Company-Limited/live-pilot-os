# LivePilot OS — Visual Evidence and Provenance SOT

> **Status:** Canonical visual QA and asset provenance contract.

Every visual baseline records reference ID, asset/font hashes, viewport, locale, theme,
browser, device scale, commit, capture command, reviewer, and approved tolerance.
Visual diffs must distinguish intentional design changes from layout, typography,
RTL, localization expansion, or state regressions. Baselines are immutable per revision;
updates require a linked decision and evidence receipt.
