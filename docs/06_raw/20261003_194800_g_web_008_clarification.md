## 1. Context & Business Intent

Accessibility is not an optional afterthought or cosmetic overlay; it is a foundational, non-negotiable engineering invariant across the Sodality ecosystem. Goal `G-WEB-008` guarantees that all interactive controls, text hierarchies, focus states, and component semantics in Soda OS web applications comply strictly with **WCAG 2.2 Level AA** standards.

Prior to G-WEB-008:
- Color contrast ratios across dark mode and light mode palettes were declared conceptually but lacked automated programmatic mathematical auditing.
- Keyboard traversal was supported ad-hoc without automated prevention of keyboard traps (such as positive `tabIndex` anti-patterns).
- Focus-visible styling was browser-default and risked being invisible or lacking sufficient contrast on dark backgrounds.
- Screen reader accessibility lacked automated verification of ARIA landmark roles, live regions, and `.sr-only` utility classes.
