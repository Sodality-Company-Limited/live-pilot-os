## Context
This goal establishes independent ceiling gates for input and output tokens in Soda OS, preventing asymmetric context overrun even when total tokens are below combined budget. Cites [`docs/07-backlog/antigravity-context.md`](file:///docs/07-backlog/antigravity-context.md).

## Intent
**Why:** Combining input and output tokens into a single sum allows oversized prompts to exhaust context windows before response generation.  
**Done when:** Independent input and output token ceilings reject oversized requests before execution begins.  
**Unblocks:** G-AG-008 and provider token budget governance.
