## Context
This goal provides bounded CLI subprocess execution in `scripts/agents/bounded-run.mjs`, enforcing process timeouts, line limits, and secret redaction. Cites [`docs/07-backlog/antigravity-context.md`](file:///docs/07-backlog/antigravity-context.md).

## Intent
**Why:** Unbounded subprocess execution can hang indefinitely, exhaust memory buffers, and leak credentials into logs.  
**Done when:** Commands execute under process timeouts, clamp output lines to maxLines, and redact tokens, keys, and authorization headers.  
**Unblocks:** G-AG-018 and safe tool execution in subagent sessions.  

## In
- Subprocess spawning, timeout timers, redaction, and line clamping in `scripts/agents/bounded-run.mjs`.
- Unit test verification in `scripts/agents/test/bounded-run.test.mjs`.

## Out

- Modifying user shell configuration.
