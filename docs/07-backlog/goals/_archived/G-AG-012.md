## Context

## Intent
**Why:** Tracking tokens only at spawn time fails to stop sessions that consume excessive tokens during multi-turn execution.  
**Done when:** Token accumulations that breach hard limits set stop: true and record stopReason: token_budget_exceeded.  
**Unblocks:** G-AG-014 and turn-by-turn budget governance.
