## Context

Training auxiliary heads or fine-tuning models must never degrade the core autoregressive text generation quality or reasoning fluency. This goal implements the language preservation objective.

## Intent

**Why:** Guarantees that training the confidence head and fine-tuning adapters does not induce catastrophic forgetting or degradation of language generation quality.

**Done when:** A PyTorch loss module computes token cross-entropy on completions and KL divergence from reference logits with finite gradients.

**Unblocks:** Parameter-efficient LoRA training pipeline (G-ML-007).

## 1. Problem and Value

- **Problem:** Absence of calibrated uncertainty estimation and reproducible ML guarantees in Soda OS agent execution.
- **Affected users or agents:** Autonomous agents making high-stakes tool execution and code generation decisions.
- **Current behavior:** Agents treat all model outputs with uncalibrated certainty, causing high-confidence errors and unverified deployments.
- **Failure cost:** Catastrophic failure in production due to silent hallucination and unmitigated risk actions.
- **Desired behavior:** Composite loss objective combining negative log-likelihood causal language modeling loss with a reference model Kullback-Leibler divergence penalty.
- **Why now:** Foundation requirement for production-grade agent reliability and formal verification.
- **If not completed:** System remains vulnerable to distribution shift, overconfidence, and silent execution corruption.

**Verification command:** `pytest tests/ml/test_language_preservation.py -k test_nll_loss`  
**Completion gate:** NLL loss computes valid float values and ignores prompt tokens with exit code 0.

### Step 2 — Implement reference model KL divergence regularization

**Allowed files:** `code/ml/src/training/losses/language_preservation.py`  
**Actions:**
1. Implement Kullback-Leibler divergence term comparing active model logits against frozen reference model logits.
2. Add configurable beta weighting coefficient controlling regularization strength.

**Verification command:** `pytest tests/ml/test_language_preservation.py -k test_kl_divergence`  
**Completion gate:** KL divergence equals 0 when active logits match reference logits exactly.  
**Stop condition:** Non-zero KL divergence for identical distributions or negative KL values.  
**Zero-Mock invariant check:** Exact mathematical KL formulation; zero mocked loss returns.

### Step 3 — Verify numerical stability and gradient backpropagation

**Allowed files:** `tests/ml/test_language_preservation.py`  
**Actions:**
1. Verify gradient backward pass on bfloat16 and float32 tensor inputs.
2. Confirm that zero NaN or Inf gradients are generated under extreme logit distributions.

**Verification command:** `pytest tests/ml/test_language_preservation.py -k test_numerical_stability`  
**Completion gate:** Numerical stability test battery passes 100% green with exit code 0.
