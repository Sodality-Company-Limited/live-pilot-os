## Context
Captures raw operational multi-CLI agent prompts, terminal outputs, tool invocations, and test outcomes across Codex, Antigravity, Gemini, Claude, Aider, Ollama, and Goose into structured, immutable JSON files to establish the Teacher LLM dataset for downstream Liquid-EBM-JEPA and DAVE distillation. Links directly with [`docs/06_raw/20261023_165354_liquid_ebm_jepa_and_dave_trajectory_engine_blueprint.md`](file:///docs/06_raw/20261023_165354_liquid_ebm_jepa_and_dave_trajectory_engine_blueprint.md).

## Intent
**Why:** Training Liquid-EBM-JEPA and the DAVE Decision/Action layer requires complete, uncompressed prompt-response pairs, tool sequences, and verification results from CLI executions rather than merely high-level metadata.  
**Done when:** All subagent invocations through `scripts/agents/lib/subagent-spawner.mjs` sanitize and write full-fidelity trajectory records to `.agents/telemetry/trajectories/<timestamp>_<goalId>_<sessionKey>.json` adhering to `schemas/agent-cognitive-trajectory.schema.json`.  
**Unblocks:** G-ML-030, G-ML-031, G-ML-032.  

## In
- Formal JSON schema `schemas/agent-cognitive-trajectory.schema.json` validating full trajectory payloads.
- Secret redaction and PII scrubbing engine for CLI prompts and terminal responses.
- Trajectory recorder integration in `scripts/agents/lib/subagent-spawner.mjs`.
- Discrete file storage in `.agents/telemetry/trajectories/`.
- Unit and integration tests in `scripts/agents/test/cognitive-trajectory-recorder.test.mjs`.

## Out
- Training model weights (handled in G-ML-031 and G-ML-032).
- Transforming trajectories into RLCD preference pairs (handled in G-ML-030).
- External network transmission of telemetry outside the local workspace.

## Work steps
### Step 1 — Implement Trajectory Schema Contract and PII / Secret Redaction Filter
**Allowed files:** `schemas/agent-cognitive-trajectory.schema.json`, `scripts/agents/lib/trajectory-sanitizer.mjs`  
**Actions:**
1. Define strict JSON schema declaring required fields: `sessionKey`, `goalId`, `provider`, `model`, `persona`, `role`, `fullPrompt`, `rawResponse`, `changedFiles`, `verification`, `digest`.
2. Implement regex and entropy-based redaction filter scrubbing API keys, JWT tokens, Bearer headers, and private keys.
**Verification command:** `node --test scripts/agents/test/trajectory-sanitizer.test.mjs`  
**Completion gate:** 100% green unit test pass verifying zero leak of injected synthetic secret tokens.  
**Stop condition:** Schema validation failure or unredacted secret leak.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.

### Step 2 — Instrument Subagent Spawner and Provider Adapters for Full-Fidelity Output Capture
**Allowed files:** `scripts/agents/lib/subagent-spawner.mjs`, `scripts/agents/lib/modular-telemetry-engine.mjs`  
**Actions:**
1. Capture raw input prompt, command arguments, full stdout/stderr stream, and execution exit status without truncation.
2. Bind physical source file SHA-256 digests before and after tool execution.
**Verification command:** `node --test scripts/agents/test/subagent-spawner.test.mjs`  
**Completion gate:** Subagent invocation produces sanitized trajectory record matching schema.  
**Stop condition:** Adapter fails to capture stdout or drops prompt metadata.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.

### Step 3 — Persist Content-Addressable Trajectory Records and Register Verification Harness
**Allowed files:** `scripts/agents/lib/cognitive-trajectory-recorder.mjs`, `scripts/agents/test/cognitive-trajectory-recorder.test.mjs`  
**Actions:**
1. Write trajectory JSON to `.agents/telemetry/trajectories/<timestamp>_<goalId>_<sessionKey>.json`.
2. Compute cryptographic SHA-256 digest of entire payload for tamper-evident data lineage.
**Verification command:** `node --test scripts/agents/test/cognitive-trajectory-recorder.test.mjs`  
**Completion gate:** Written files parse successfully, validate against schema, and match computed digest.  
**Stop condition:** Write collision, invalid digest, or corrupt JSON payload.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.
