## Context
Trains a continuous-time Liquid Neural Network (LNN) governed by non-linear Ordinary Differential Equations ($\frac{dx}{dt} = -\tau(I(t)) \cdot x(t) + f(x(t), I(t), \theta)$) using multi-turn CLI agent temporal sequences generated in G-ML-029 and G-ML-030. Bridges the heavy Teacher LLM execution trajectories into a high-speed reflexive action router. Aligned with [`docs/06_raw/20261023_165354_liquid_ebm_jepa_and_dave_trajectory_engine_blueprint.md`](file:///docs/06_raw/20261023_165354_liquid_ebm_jepa_and_dave_trajectory_engine_blueprint.md) and [`sodality-aether/docs/06_raw/20260623_143444_aether_teacher_llm_training_jepa_ebm_liquid.md`](file:///sodality-aether/docs/06_raw/20260623_143444_aether_teacher_llm_training_jepa_ebm_liquid.md).

## Intent
**Why:** Heavy CLI LLMs require seconds to generate responses; reflexive routing and continuous environment adaptation require continuous-time differential dynamics executing in under 3 milliseconds.  
**Done when:** Continuous-time Liquid ODE network trains on temporal CLI trajectory sequences under `conda activate py310`, achieving Mean Squared Error $\le 0.05$ across state dynamics and benchmarked single-step inference latency $\le 3.0\text{ms}$.  
**Unblocks:** G-OPS-001.

## Work steps
### Step 1 — Sequential Time-Series Trajectory Tokenizer and ODE State Formatter
**Allowed files:** `scripts/ml/dataset_liquid_trajectories.py`, `tests/ml/test_liquid_ode_engine.py`  
**Actions:**
1. Parse multi-turn CLI agent trajectories into continuous-time observation sequences $(t_i, I(t_i), y(t_i))$.
2. Normalize time steps $\Delta t$ and embed tool responses into continuous state coordinates.
**Verification command:** `pytest tests/ml/test_liquid_ode_engine.py -k test_dataset_sequence`  
**Completion gate:** 100% green pytest verifying sequential temporal tensor construction.  
**Stop condition:** Time step inversion or NaN values in input streams.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.

### Step 2 — Continuous-Time Liquid ODE Solver with Adjoint Sensitivity Backpropagation
**Allowed files:** `scripts/ml/models/liquid_neural_ode.py`, `scripts/ml/train_liquid_ode_trajectories.py`  
**Actions:**
1. Implement variable time-constant ODE dynamics $\frac{dx}{dt} = -\tau(I(t)) \cdot x(t) + f(x(t), I(t), \theta)$.
2. Integrate forward with RK4 ODE solver and backpropagate gradients using continuous adjoint methods.
**Verification command:** `pytest tests/ml/test_liquid_ode_engine.py -k test_ode_training`  
**Completion gate:** Training MSE loss converges below 0.05 across validation sequences.  
**Stop condition:** Stiff ODE divergence or gradient explosion during integration.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.

### Step 3 — Low-Latency Benchmark and Sub-3ms Reflexive Routing Validation
**Allowed files:** `scripts/ml/benchmark_liquid_latency.py`, `artifacts/checkpoints/`  
**Actions:**
1. Benchmark single-step ODE inference latency across 1,000 iterations.
2. Certify latency SLA $\le 3.0\text{ms}$ with zero JIT compilation stalls.
**Verification command:** `pytest tests/ml/test_liquid_ode_engine.py -k test_latency_sla`  
**Completion gate:** Mean inference latency $\le 3.0\text{ms}$; 99th percentile $\le 5.0\text{ms}$.  
**Stop condition:** Latency SLA violation.  
**Zero-Mock invariant check:** 100% operational implementation; zero stubs, zero mocks, zero placeholders.
