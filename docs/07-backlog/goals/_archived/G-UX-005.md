## Context

The Multimodal UX/UI Design Decision Making Layer requires high-fidelity visual comprehension of user interfaces. Rather than treating screenshots as ungrounded opaque embeddings or relying on external cloud APIs, Soda OS standardizes on Google Gemma 4 native multimodal vision capabilities. Gemma 4 features a high-resolution SigLIP ViT vision encoder projecting patch tokens directly into the model context space.

## Intent

Standardize visual perception inputs, viewport letterboxing, patch tiling, and projection representations to feed downstream scene graph generation.

**Why:** Grounding layout decisions in high-resolution visual tokens eliminates text hallucinations and enables accurate structural reasoning across viewports.  
**Done when:** All letterboxing, patch tiling, GELU MLP projection, and token budget assertions pass with exit code 0.  
**Unblocks:** G-UX-006 (OCR Bounding Box Aligner) and G-UX-007 (Deterministic UI Scene Graph Generator).

## How

Implement the native vision adapter in Python (`code/ml/src/vision/gemma4_multimodal_adapter.py`) and ES Module JavaScript (`scripts/lib/gemma4-vision-adapter.mjs`). Standardize canonical viewports (Desktop 1440x900, Tablet 1024x768, Mobile 390x844). Pad with Slate-900 `rgb(15, 23, 42)`. Dynamic tiling partitions images into $448 \times 448$ pixel tiles (up to 6 grid tiles + 1 global thumbnail = 7 tiles total = 1,792 tokens). Project vision dimension $d_v = 1152$ to model dimension $d_m = 4096$ via a 2-layer GELU MLP with LayerNorm.
