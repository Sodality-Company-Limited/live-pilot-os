## Context

While vision transformer tokens capture overall spatial layouts and component boundaries, small text labels and micro-copy are extracted with highest precision by optical character recognition (OCR) models. To construct high-fidelity UI Scene Graphs, visual bounding boxes must be aligned and fused with OCR text detections on a normalized integer grid without text hallucination.

## Intent

Normalize multimodal visual bounding boxes and fuse OCR text detections into unified component nodes with spatial and stacking relationships.

**Why:** Grounding visual boxes with verified OCR strings asserts IoU >= 0.90 to eliminate text hallucinations.  
**Done when:** Coordinate normalization, pairwise IoU, natural reading order fusion, and spatial relations pass all verification tests with exit code 0.  
**Unblocks:** G-UX-007 (Deterministic UI Scene Graph Generator) and G-UX-008 (Vision Detector Benchmark Spike).

## How

Implement coordinate normalization to integer grid $[0, 1000] \times [0, 1000]$ in Python (`code/ml/src/vision/ocr_bounding_box_aligner.py`) and JavaScript (`scripts/lib/ocr-bbox-aligner.mjs`). Implement pairwise Intersection-over-Union (IoU) and enclosure metrics. Apply exact match rule ($\text{IoU} \ge 0.90$) to fuse text directly into visual nodes, and enclosure rule ($\text{IoU} < 0.90, \text{enclosure} \ge 0.85$) to capture nested child labels. Sort child text tokens in natural reading order ($y_{\text{norm}}$ then $x_{\text{norm}}$). Derive pairwise directional (`above`, `below`, `left_of`, `right_of`) and alignment (`aligned_left`, `aligned_top`, `centered_horizontal`, `contains`) relations.
