## Context

Flat bounding box lists cannot capture the hierarchical, recursive nature of modern user interfaces (Flexbox, Grid, modals, stacking contexts). A formal Directed Acyclic Graph (DAG) provides an unambiguous topological representation connecting visual elements with containment (`parent_child`), spatial proximity (`sibling`), and stacking order (`z_index_layer`).

## Intent

Synthesize deterministic, acyclic UI scene graphs verified via Kahn's topological sort and bound by cryptographic SHA-256 digests.

**Why:** A formal acyclic DAG structure guarantees that downstream React AST generators and accessibility auditors operate on a valid, cycle-free layout hierarchy.  
**Done when:** Scene graph generation, 32-class taxonomy validation, Kahn topological sorting, cycle detection, and SHA-256 digests pass cleanly.  
**Unblocks:** G-UX-008 (Vision Detector Benchmark Spike) and G-UX-009 (UI Taxonomy & Labeling Curriculum).

## How

Author `schemas/ui-scene-graph.schema.json` under Draft 2020-12. Implement the scene graph generator in Python (`code/ml/src/vision/scene_graph_generator.py`) and JavaScript (`scripts/lib/ui-scene-graph.mjs`). Classify nodes into 32 canonical UI classes across 6 categories. Establish edge taxonomy (`parent_child`, `sibling`, `visual_containment`, `z_index_layer`). Implement Kahn's algorithm for topological sorting and cycle detection, throwing `CyclicSceneGraphError` fail-closed upon cycle detection. Sort nodes deterministically ($z_{\text{index}} \to y_{\text{norm}} \to x_{\text{norm}} \to \text{node\_id}$). Compute deterministic SHA-256 digest over canonicalized graph representation.
