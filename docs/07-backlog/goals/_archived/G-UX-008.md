## Context

Architectural trade-off decisions between end-to-end multimodal perception versus decoupled object detectors must be grounded in empirical data. The system must quantitatively compare latency distributions, bounding box precision (mAP@50 and mAP@50:95), scene graph topological acyclicity, and semantic reasoning capacity across candidate architectures.

**Why:** Grounding architectural decisions in empirical trial distributions proves that Gemma 4 provides 100% acyclic DAG fidelity and superior semantic reasoning within sub-250ms SLA bounds.  
**Done when:** Benchmark runner executes >= 50 trial episodes, computes latency distributions, and scorecard verification harness passes with exit code 0.
