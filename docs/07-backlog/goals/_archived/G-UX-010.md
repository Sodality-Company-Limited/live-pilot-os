## Context

Training multimodal UI perception models requires high-volume, structured paired datasets linking visual layouts with ground-truth Directed Acyclic Graphs. The dataset must cover multiple viewport dimensions, establish topological node ordering, and guarantee zero sample contamination between evaluation splits.

## Intent

Generate and curate a 5,000-record paired dataset linking UI layouts to verified acyclic scene graph DAGs across 3 viewports with strict 80/10/10 train/validation/test partitions.

**Why:** Supervised fine-tuning and visual perception validation require verified ground-truth DAGs with guaranteed topological acyclicity and orthogonal evaluation splits.  
**Done when:** 5,000 records generated, 80/10/10 partition verified with 0 sample leakage, and harness passes with exit code 0.  
**Unblocks:** G-UX-011 (Stage 3 UX Heuristics & WCAG Benchmark), G-UX-015 (SFT Pipeline).

## How

Implement `scripts/lib/scene-graph-dataset-generator.mjs` and `code/ml/src/curriculum/scene_graph_dataset.py`. Generate 5,000 paired records across Desktop (40%, 2000), Tablet (30%, 1500), and Mobile (30%, 1500). Partition deterministically into 4,000 train, 500 validation, and 500 test records in `artifacts/curriculum/stage2_scene_graphs/`. Verify Kahn topological sort and zero sample leakage. Test via `tests/unit/test-scene-graph-dataset.mjs`, `tests/ml/test_curriculum_scene_graph.py`, and `scripts/harness/scene-graph-dataset-harness.mjs`.
