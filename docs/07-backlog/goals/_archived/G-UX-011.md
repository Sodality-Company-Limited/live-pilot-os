## Context

Evaluating UI designs requires standardized benchmarks assessing usability heuristics and accessibility standards. Models must be calibrated against expert ground-truth ratings spanning all 10 Nielsen heuristics and core WCAG 2.2 AAA criteria.

## Intent

Curate 1,200 standardized benchmark scenarios evaluating Nielsen's 10 usability heuristics and WCAG 2.2 AAA accessibility rules with quantitative severity scores and actionable suggested fixes.

**Why:** Grounding heuristic evaluation models requires comprehensive benchmarks providing multimodal rationales and remediation guidance across the entire 0-4 severity spectrum.  
**Done when:** 1,200 scenarios generated in `artifacts/curriculum/stage3_heuristics/`, full coverage of Nielsen 10 and WCAG criteria verified, and harness passes with exit code 0.  
**Unblocks:** G-UX-012 (Persona Trajectories), G-UX-021 (UX Expert Agreement Benchmark).

## How

Implement `scripts/lib/ux-heuristics-benchmark.mjs` and `code/ml/src/curriculum/heuristics_benchmark.py`. Generate 1,200 scenarios: 600 Nielsen (H1-H10, severity 1-4), 420 WCAG 2.2 AAA (contrast, keyboard traps, focus rings, touch targets), and 180 clean baseline controls (severity 0). Each scenario provides title, category, heuristic ID, severity, multimodal rationale, and suggested CSS/DOM remediation. Verify with `tests/unit/test-ux-heuristics-benchmark.mjs`, `tests/ml/test_curriculum_heuristics.py`, and `scripts/harness/ux-heuristics-benchmark-harness.mjs`.
