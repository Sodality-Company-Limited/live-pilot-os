## Context

Autonomous UX reasoning requires multi-perspective deliberation traces modeling diverse stakeholder perspectives, precedence rules, and fail-closed safety constraints. Machine learning agents trained on single-perspective decisions lack nuance and fail to handle trade-offs between accessibility, aesthetics, cognitive load, and business goals.

## Intent

Synthesize 2,500 deliberation trajectories across all 12 UX specialist personas with 10-state life-cycle transitions, 4-tier precedence resolution, and token budget enforcement.

**Why:** Equipping generative agents with multi-agent deliberation reasoning requires high-density training trajectories capturing collaborative convergence, conflict mitigation, and safety vetoes.  
**Done when:** 2,500 trajectories generated in `artifacts/curriculum/stage4_trajectories/`, all 12 personas participate, precedence resolution verified, and harness passes with exit code 0.  
**Unblocks:** G-UX-013 (Contrastive Preference Dataset), G-UX-021 (UX Expert Agreement Benchmark).

## How

Implement `scripts/lib/persona-trajectory-builder.mjs` and `code/ml/src/curriculum/persona_trajectories.py`. Model all 12 UX personas with calibrated expertise domains, priority tiers, and token expenditure budgets. Execute 10-state deliberation life cycles (`INGEST_SCENE_GRAPH` through `TERMINATE`). Resolve agent collisions using Tier 1 vetoes and consensus scoring. Export 2,500 trajectories (80% `EMIT_DECISION`, 10% `DEFER`, 10% `REJECT_AS_UNSAFE`). Validate with unit tests and `scripts/harness/persona-trajectory-harness.mjs`.
