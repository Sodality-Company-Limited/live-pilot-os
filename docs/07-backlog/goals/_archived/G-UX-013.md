## Context

Aligning generative UX models requires contrastive learning datasets that expose subtle design defects against verified canonical solutions. Without explicit paired comparisons (chosen vs. rejected), models frequently generate antipatterns such as unhandled error states, hardcoded color literals, and inaccessible touch targets.

## Intent

Construct a contrastive preference dataset comprising 3,500 DPO pairs and 7,000 KTO records spanning an 8-flaw design taxonomy with Kahneman-Tversky loss aversion weighting.

**Why:** Direct Preference Optimization (DPO) and Kahneman-Tversky Optimization (KTO) alignment require high-quality contrastive pairs with measurable preference margins and balanced splits.  
**Done when:** 3,500 pairs exported in `artifacts/curriculum/stage5_preferences/`, 80/10/10 splits verify 0 sample contamination, KTO records generated with $\lambda = 1.33$, and harness passes with exit code 0.  
**Unblocks:** G-UX-014 (Adversarial Dark Patterns), G-UX-021 (UX Expert Agreement Benchmark).

## How

Implement `scripts/lib/dpo-kto-dataset-builder.mjs` and `code/ml/src/curriculum/preference_dataset.py`. Define an 8-flaw taxonomy covering color literals, WCAG contrast failures, missing focus indicators, dark patterns, typographic scale drifts, missing ARIA roles, unhandled error states, and undersized touch targets. Synthesize 3,500 chosen/rejected pairs with delta scores. Generate 7,000 binary KTO records with loss aversion multiplier $\lambda = 1.33$. Partition into 80/10/10 disjoint splits (2,800 train, 350 val, 350 test). Verify with unit tests and `scripts/harness/dpo-kto-dataset-harness.mjs`.
