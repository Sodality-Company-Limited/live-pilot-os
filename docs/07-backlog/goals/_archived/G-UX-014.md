## Context

Production UI systems face adversarial manipulation and privacy leakage risks. Generative models must be immunized against deceptive UI patterns (confirmshaming, hidden costs, forced continuity) and trained to gracefully defer when presented with ambiguous or occluded inputs, while strictly scrubbing all PII before inference.

## Intent

Deliver an adversarial curriculum comprising 800 red-team scenarios (400 deceptive patterns, 400 deferral traps) and an automated regex PII scrubber with Luhn credit card validation.

**Why:** Robustness against manipulation and privacy compliance require empirical training data enforcing fail-closed boundaries (`REJECT_AS_UNSAFE`, `DEFER`) and zero raw credential exposure.  
**Done when:** 800 red-team scenarios exported in `artifacts/curriculum/stage6_adversarial/`, fail-closed routing verified for 14 dark patterns and 5 deferral traps, PII sanitizer validated, and harness passes with exit code 0.  
**Unblocks:** G-UX-020 (Autonomous UI Auditing), G-UX-021 (UX Expert Agreement Benchmark).

## How

Implement `scripts/lib/dark-pattern-curriculum.mjs` and `code/ml/src/curriculum/redteam_pii_sanitizer.py`. Codify 14 deceptive dark patterns (confirmshaming, sneak into basket, fake urgency, hidden costs, etc.) routing strictly to `REJECT_AS_UNSAFE`. Codify 5 deferral categories (low visual clarity, ambiguous prompt, occlusion, etc.) routing to `DEFER`. Implement regex PII scrubber covering emails, phone numbers, SSNs, API tokens (AWS, OpenAI, GitHub), and Luhn-valid credit card numbers. Verify with unit tests and `scripts/harness/dark-pattern-curriculum-harness.mjs`.
