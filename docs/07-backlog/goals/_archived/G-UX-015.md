## Context

Raw vision-language models struggle to generate structured, syntactically conforming, and domain-grounded UX decision contracts without specialized instruction tuning. Multimodal Supervised Fine-Tuning aligns generative foundations with explicit UI scene graphs, multi-agent persona trajectories, and strict JSON schema contracts.

## Intent

Train generative foundations to emit fully valid UX Decision JSON contracts conditioned on acyclic UI scene graphs and 12-persona constraints with high structural accuracy.

**Why:** Grounding multimodal generation in structured UI scene graph hierarchies and persona constraints guarantees structural validity, domain fidelity, and strict schema compliance.  
**Done when:** SFT trainer and pipeline are operational, chat templates format multimodal context deterministically, cross-entropy loss masks prompt tokens, and validation achieves at least 98.0% schema conformance.  
**Unblocks:** G-UX-016 (Multimodal DPO Pipeline), G-UX-017 (Calibration-Aware RL).

## How

Implement PyTorch SFT trainer in `code/ml/src/training/sft_trainer.py` and Node.js SFT pipeline in `scripts/lib/ux-sft-pipeline.mjs`. Ingest Stage 2 UI scene graphs and Stage 4 multi-agent trajectories. Implement chat template formatter structuring system prompt, scene-graph JSON context, and persona directives. Compute token-level cross-entropy loss with prompt token masking (`labels = -100`). Verify $\ge 98.0\%$ schema conformance against `schemas/ux-decision-contract.schema.json` via unit tests and `scripts/harness/ux-sft-pipeline-harness.mjs`.

- Rejection of malformed scene graph payloads without throwing uncaught exceptions.
