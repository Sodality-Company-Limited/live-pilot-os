## Context

While supervised fine-tuning ensures syntactically valid JSON output, it cannot distinguish between subtly inferior and superior UX choices without explicit contrastive alignment. Multimodal Direct Preference Optimization (DPO) aligns policy likelihoods against pairwise human and expert preference distributions.

## Intent

Optimize decision policy likelihoods over contrastive pairs using closed-form preference optimization with frozen reference policy.

**Why:** Direct preference optimization eliminates unstable reinforcement learning reward models while guaranteeing policy alignment with superior UX trade-offs.  
**Done when:** DPO trainer and pipeline are operational, Bradley-Terry objective is computed with beta 0.20 and frozen reference policy, and held-out win rate achieves at least 68.0%.  
**Unblocks:** G-UX-017 (Calibration-Aware RL), G-UX-018 (Multi-Agent LoRA Merging).

## How

Implement PyTorch DPO trainer in `code/ml/src/training/dpo_trainer.py` and Node.js DPO pipeline in `scripts/lib/ux-dpo-pipeline.mjs`. Ingest Stage 5 contrastive preference dataset from `artifacts/curriculum/stage5_preferences/`. Compute Bradley-Terry DPO objective using temperature parameter $\beta = 0.20$ with reference model parameter freezing. Evaluate empirical win rate on held-out test split pairs ($N=350$) ensuring $\ge 68.0\%$ win rate over the SFT baseline. Verify with unit tests and `scripts/harness/ux-dpo-pipeline-harness.mjs`.

## 5-Tier Test Suite Specification

### 1. Positive Tests
- DPO policy achieves $\ge 68.0\%$ win rate over SFT baseline on 350 test pairs.
- Bradley-Terry loss yields positive implicit reward margins for chosen completions.

### 2. Negative Tests
- Rejection of non-positive beta temperature values with fail-closed exception.
- Rejection of unbalanced prompt tokens between chosen and rejected candidates.

### 3. Fail-Closed & Chaos Tests
- Reference model gradients are strictly disabled; any weight drift raises assertion.
- Underflow or overflow in log-sigmoid computation fails closed.

### 4. Temporal Causality Tests
- Deterministic pseudo-random seed guarantees bitwise identical pairwise win rates.

### 5. Security & Air-Gap Checks
- Air-gapped local execution without external network telemetry calls.
- Strict isolation of local dataset buffers from external network interfaces.
