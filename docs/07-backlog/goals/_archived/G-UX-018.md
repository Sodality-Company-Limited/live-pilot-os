## Context

Deploying 12 full-parameter foundation models for 12 UX specialist personas is computationally prohibitive and incurs severe memory overhead. Low-Rank Adaptation (LoRA) enables lightweight, persona-specific parameter updates that can be dynamically routed and mathematically merged at runtime.

## Intent

Provide lightweight parameter adaptation across 12 personas with support for linear, TIES, and DARE weight merging.

**Why:** Multi-agent deliberation requires fast persona switching and composite policy synthesis without duplicating massive foundation model weights.  
**Done when:** PyTorch LoRA merger and Node.js adapter registry are operational, zero-initialization invariant ($B=0$) is verified, Linear, TIES, and DARE merging pass cleanly, and adapter swapping latency is under 50ms.  
**Unblocks:** G-UX-019 (Model Provenance Ledger), G-UX-020 (Autonomous UI Auditing).

## How

Implement PyTorch LoRA merger in `code/ml/src/training/lora_merger.py` and Node.js adapter registry in `scripts/lib/lora-adapter-registry.mjs`. Register all 12 UX personas ($r=16, \alpha=32$). Enforce strict zero-initialization invariant ($B = \mathbf{0}, A \sim \mathcal{N}(0, 1/\sqrt{r})$) guaranteeing identity transformation $\Delta W = 0$ at step 0. Implement 3 parameter merging algorithms: Linear weighted averaging, TIES-Merging (trimming, sign election, disjoint merge), and DARE (drop-and-rescale pruning). Benchmark runtime persona switching ($< 50\text{ms}$). Verify with unit tests and `scripts/harness/lora-adapter-registry-harness.mjs`.
