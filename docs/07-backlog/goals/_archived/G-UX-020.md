## Context

Statistical calibration is critical for autonomous multimodal UX decision making to prevent overconfident hallucinations and underconfident paralysis. Decision systems must quantify uncertainty precisely, ensuring that stated confidences correspond to empirical accuracy distributions.

## Intent

Implement a multi-bin statistical calibration verification harness evaluating Expected Calibration Error, Brier score, and High-Confidence Error Rate.

**Why:** Safe autonomous systems must possess well-calibrated confidence distributions bounded by empirical Brier and Expected Calibration Error thresholds.  
**Done when:** Multi-bin calibration harness evaluates 10-bin ECE, Brier score, AUROC trapezoidal integration, HCER on high-confidence samples (c >= 0.80), Wilson score binomial intervals, and 1,000 bootstrap iterations.  
**Unblocks:** G-UX-021 (UX Expert Heuristic Agreement Benchmark), G-UX-022 (Automated WCAG 2.2 AAA Contrast & Keyboard Gate), G-UX-023 (Adversarial Dark-Pattern Rejection Safety Gate).

## How

Implement `scripts/lib/statistical-calibration-harness.mjs` with exact mathematical implementations of 10-bin equal-width ECE:
$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
Compute Brier score as mean squared error between probabilities and binary labels, trapezoidal AUROC in $O(N \log N)$, High-Confidence Error Rate (HCER) for samples with confidence $c \ge 0.80$, Wilson score continuity-corrected confidence intervals, and 1,000 bootstrap resamplings. Build bitwise Python parity in `code/ml/src/eval/calibration_evaluator.py`. Test in dual runtimes (`node --test` and `pytest in py310`), and enforce gate criteria via `scripts/harness/statistical-calibration-gate-harness.mjs`.

## 5-Tier Test Suite Specification

### 1. Positive Tests
- Perfect calibration predictions $(c_i = y_i)$ yield $\text{ECE} = 0.000$ and minimal Brier score.
- Synthetic calibrated enterprise distributions achieve $\text{ECE} \le 0.050$, $\text{Brier} \le 0.150$, $\text{HCER} \le 0.010$, and $\text{AUROC} \ge 0.850$.

### 2. Negative Tests
- Inverted calibration $(c_i = 1 - y_i)$ yields high calibration error ($\text{ECE} \ge 0.800$) and high Brier score ($\ge 0.800$).
- High-confidence errors ($c \ge 0.80$ with $y = 0$) are strictly detected and penalize HCER.

### 3. Fail-Closed & Chaos Tests
- Empty sample array or single-class distributions fail closed with descriptive exceptions or deterministic fallbacks.
- Uncalibrated models trigger fail-closed rejection in `scripts/harness/statistical-calibration-gate-harness.mjs`.

### 4. Temporal Causality Tests
- Deterministic random seeding in bootstrap resampling guarantees bitwise identical confidence intervals across test runs.

### 5. Security & Air-Gap Checks
- Local compute execution without telemetry leaks or external API calls.
- Evaluation runs strictly inside sandbox environments without privileged access requirements.
