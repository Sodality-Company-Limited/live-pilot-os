## Context

UX evaluation requires objective benchmarks to validate whether multimodal decision models match the rigorous evaluations of senior human UX researchers. Standard classification metrics fail to capture the ordinal penalty of severe rating discrepancies; inter-rater agreement statistics (Cohen's Kappa and Quadratic Weighted Kappa) provide formal mathematical rigor.

## Intent

Implement a 100-scenario gold-standard UX expert agreement benchmark measuring inter-rater reliability across Nielsen's 10 usability heuristics.

**Why:** Objective human-AI alignment requires measurable inter-rater agreement against consensus human UX expert ratings.  
**Done when:** Gold-standard benchmark evaluates 100 curated UI scenarios across Nielsen's 10 heuristics, computing Cohen's Kappa, Quadratic Weighted Kappa, 5x5 confusion matrix, and per-heuristic reliability.  
**Unblocks:** G-UX-022 (Automated WCAG 2.2 AAA Contrast & Keyboard Gate), G-UX-023 (Adversarial Dark-Pattern Rejection Safety Gate).

## How

Implement `scripts/lib/ux-expert-agreement-benchmark.mjs` codifying 100 gold-standard enterprise UI scenarios with severity ratings from 0 (no violation) to 4 (catastrophic usability violation) across Nielsen's 10 heuristics. Formulate exact unweighted Cohen's Kappa:
$$\kappa = \frac{p_o - p_e}{1 - p_e}$$
and quadratic weighted kappa using distance matrix $w_{ij} = 1 - \frac{(i-j)^2}{16}$:
$$\kappa_w = 1 - \frac{\sum_{i,j} w_{ij} O_{ij}}{\sum_{i,j} w_{ij} E_{ij}}$$
Implement identical Python mathematics in `code/ml/src/eval/expert_agreement.py`. Verify across dual test runtimes, and enforce $\kappa \ge 0.800$ and $\kappa_w \ge 0.850$ via `scripts/harness/ux-expert-agreement-harness.mjs`.

## 5-Tier Test Suite Specification

### 1. Positive Tests
- Identical rating vectors produce $\kappa = 1.000$ and $\kappa_w = 1.000$.
- Enterprise model evaluations achieve $\kappa = 0.850$ and $\kappa_w = 0.969 \ge 0.850$ on 100 benchmark scenarios.

### 2. Negative Tests
- Inverse ratings (0 vs 4) produce strong negative kappa ($\kappa \le -0.200$).
- Off-by-one severity differences receive moderate quadratic penalization without catastrophic failure.

### 3. Fail-Closed & Chaos Tests
- Unequal length rating vectors throw validation exceptions immediately.
- Out-of-bounds severity values ($< 0$ or $> 4$) fail closed without silent clamping.

### 4. Temporal Causality Tests
- Deterministic 100-scenario dataset order ensures bitwise identical evaluation runs.

### 5. Security & Air-Gap Checks
- Air-gapped benchmark execution without external network telemetry calls.
- Evaluation runs strictly inside local sandboxes.
