## Context

Universal accessibility is a foundational human right and a legal compliance mandate (European Accessibility Act, Section 508, ADA). Autonomous design generators risk generating low-contrast palettes or inaccessible keyboard traps unless constrained by an automated, fail-closed safety gate enforcing WCAG 2.2 Level AAA standards.

## Intent

Implement an automated WCAG 2.2 AAA safety gate enforcing strict visual contrast ratios and keyboard trap-free focus navigation graphs.

**Why:** Universal accessibility is a non-negotiable safety invariant ensuring digital products remain perceivable and operable for users with disabilities.  
**Done when:** Safety gate evaluates WCAG 2.2 AAA contrast ratios (7:1 normal, 4.5:1 large, 3:1 UI), alpha compositing, keyboard trap detection, positive tabindex rejection, and modal escape handlers.  
**Unblocks:** G-UX-023 (Adversarial Dark-Pattern Rejection Safety Gate).

## How

Implement `scripts/lib/wcag-aaa-safety-gate.mjs` parsing CSS color formats (hex, rgb, rgba) and computing alpha blending against solid backgrounds. Compute relative luminance using the W3C sRGB piecewise gamma formula:
$$c' = \frac{c}{255}, \quad c_{\text{linear}} = \begin{cases} \frac{c'}{12.92} & c' \le 0.04045 \\ \left(\frac{c' + 0.055}{1.055}\right)^{2.4} & c' > 0.04045 \end{cases}$$
$$L = 0.2126 R_{\text{linear}} + 0.7152 G_{\text{linear}} + 0.0722 B_{\text{linear}}$$
Compute contrast ratio $\frac{L_1 + 0.05}{L_2 + 0.05}$ and enforce 7.0:1 for normal text, 4.5:1 for large text, and 3.0:1 for UI components. Build keyboard graph analysis checking for cycle traps, positive tabindex anti-patterns, accessible names, and modal Escape handlers. Provide bitwise Python parity in `code/ml/src/eval/wcag_safety_gate.py`. Verify across dual runtimes and enforce fail-closed rejection via `scripts/harness/wcag-aaa-safety-gate-harness.mjs`.

## 5-Tier Test Suite Specification

### 1. Positive Tests
- High contrast pairs (black on white 21:1, indigo-800 on white 9.9:1) pass AAA thresholds.
- Connected acyclic keyboard navigation graphs pass with zero violations.

### 2. Negative Tests
- Low contrast text pairs (e.g. 1.5:1 or 4.0:1 normal text) are rejected fail-closed.
- Elements with positive `tabindex` (e.g. `tabindex="5"`) trigger validation errors.

### 3. Fail-Closed & Chaos Tests
- Dead-end interactive elements without outbound focus transitions fail closed.
- Modals missing Escape key event handlers are rejected immediately.

### 4. Temporal Causality Tests
- Deterministic focus order matching DOM tree structure without unexpected leaps.

### 5. Security & Air-Gap Checks
- Air-gapped local execution without external network telemetry calls.
- Safe regex color parsers immune to catastrophic polynomial backtracking (ReDoS).
