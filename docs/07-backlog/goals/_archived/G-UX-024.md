## Context

Design-to-code pipelines frequently emit unmaintainable code laden with raw hex color codes, arbitrary inline styles, and unmanaged component states. To guarantee that generated frontend code strictly adheres to design systems and accessibility standards, Soda OS compiles verified UI Scene Graphs directly into headless Babel/ESTree compliant React TSX AST structures while enforcing zero raw styling literals and complete 5-state component coverage.

## Intent

Compiles UI scene graphs and verified UX decisions into Babel/ESTree compliant React TSX AST structures with token guardrails.

**Why:** Enforces zero raw literals and guarantees design token bindings, accessibility roles, and 5-state component coverage during code emission.  
**Done when:** AST generator transforms scene graph DAGs into ESTree TSX ASTs, rejects raw hex and arbitrary pixel dimensions fail-closed, verifies 5 component states, and outputs clean TSX code.  
**Unblocks:** Automated design-to-code component generation across Soda OS.

## How

Implement `scripts/lib/react-ast-generator.mjs` providing `compileSceneGraphToReactAst` and `compileSceneNodeToJsx`. Map the 32 canonical component taxonomy classes into valid semantic JSX elements. Attach WCAG AAA accessibility attributes (`role`, `aria-label`, `tabIndex`). Provide complete 5-state token classes (`default`, `hover`, `active`, `disabled`, `focus`) for every interactive component. Implement `assertZeroRawLiterals` and AST walker `validateAstTokenConformance` detecting raw hex colors (`#...`), rgb/rgba literals, or arbitrary pixel dimensions (`px`), throwing `TokenViolationError` fail-closed. Build deterministic code printer `printTsx`. Verify via unit tests in `tests/unit/test-react-ast-generator.mjs` and domain harness `scripts/harness/react-ast-guardrail-harness.mjs`.
