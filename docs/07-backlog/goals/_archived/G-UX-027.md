## Context

Autonomous AI decision orchestration requires continuous mathematical calibration monitoring to detect model confidence drift, overconfidence bugs, and tail latency regressions before degradation harms production safety. Monitoring systems must track rolling 10-bin Expected Calibration Error (ECE $\le 0.050$), Brier score ($\le 0.150$), and High-Confidence Error Rate (HCER $\le 0.020$) while maintaining exact integer multi-currency token cost accounting.

## Intent

Implements streaming runtime telemetry tracking 10-bin ECE calibration, Brier score, and latency SLAs with zero-float multi-currency accounting.

**Why:** Enforces mathematical bounds on autonomous decision quality and isolates degrading models via fail-closed circuit breakers.  
**Done when:** Rolling window ECE, Brier, HCER, P50/P90/P99 latency, and token cost accounting are computed online with automatic circuit breaker transitions.  
**Unblocks:** Autonomous operational safety and self-governing agent execution across Soda OS.

## How

Implement `scripts/lib/ux-calibration-drift-monitor.mjs` exporting `UxCalibrationDriftMonitor` and `CircuitBreakerState`. Maintain a fixed-capacity sliding window of decision records. Calculate 10-bin uniform partition ECE:
$$\text{ECE} = \sum_{m=1}^{M} \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$
Compute empirical Brier score:
$$\text{BS} = \frac{1}{N} \sum_{i=1}^N (c_i - o_i)^2$$
Compute HCER for $c_i \ge 0.90$. Calculate nearest-rank P50, P90, P99 latency percentiles. Track token cost expenditure using the universal `Money` Value Object with zero float representation. Trigger circuit breaker state transitions across `CLOSED`, `TRIPPED_DEFER`, `TRIPPED_REJECT`, and `HALF_OPEN`. Verify via unit tests in `tests/unit/test-ux-telemetry-monitor.mjs` and domain harness `scripts/harness/ux-telemetry-drift-harness.mjs`.
